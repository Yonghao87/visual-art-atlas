# 成人与亲子双版本规范

用户最新要求（2026-10-12）：后续正式档案必须有实际配图，封面、至少一件作品及亲子引用作品采用获准使用的真实照片、扫描图或实作/软件截图（JPG/PNG/WebP/AVIF），不使用SVG或转成栅格的示意图替代。无合适实图时保留候选并暂停发布。完整要求见 [图片收录原则](IMAGE_COLLECTION_POLICY.md#后续正式档案的实际配图要求2026-10-12起)。下文旧档案/MVP示意规则只保留兼容，不适用于后续新发布。

同一篇艺术档案提供成人阅读与 5–7 岁亲子共读，共用主题、日期、ID、作品、来源和许可。亲子版是美育阅读：用孩子能理解的语言介绍艺术、解释作品怎样表达，再鼓励个人感受，不以找不同、数物件或答对问题为主。现有八篇已按认可的印象派样稿统一调整。

## 阅读与写作顺序

1. **认识艺术**：说清楚这是什么艺术、媒介或设计方法，适用时介绍创作者。两三句短介绍即可，不堆艺术史，也不编故事、对白或作者动机。
2. **完整欣赏**：先给孩子看 1–2 件完整作品，文字帮助进入作品，不急着提问。
3. **理解表达**：用 2–4 个短小节解释具体可见的颜色、线条、笔触、材料、造型、空间或版面。新术语就地解释，例如“画笔留下的痕迹叫笔触”。不同领域选择不同维度，不套用同一份清单。
4. **局部与整体对应**：需要时提供 1–2 张有讲解价值的原图局部，旁边说明它如何帮助理解艺术。讲解后回看完整作品，联系局部与整体。局部不是必填，也不为凑数放大无关区域。
5. **表达感受**：只留一个开放的感受引导，允许用词、动作或声音表达。大人倾听，再一起回到作品，不要求标准答案。
6. **回到生活**：一句话连接孩子熟悉的生活。动手活动为可选折叠内容，也可以省略；只欣赏与交谈就是完整阅读。

主阅读文本建议约 300–600 字，不计署名、大人提示和可选活动；可按主题调整，以读得懂为先。短句讲清具体关系，避免成人理论缩写、空泛赞美和连续问答。不要求模仿原作、证明孩子观察正确或每次完成手工。

## 数据契约

成人版保留根层字段，亲子版写在可选的 `children` 对象内。

| 字段                | 约定                                                     |
| ------------------- | -------------------------------------------------------- |
| `ageRange`          | 固定 `5-7`                                               |
| `title` / `summary` | 带主题的儿童标题、艺术/创作者介绍                        |
| `looking`           | 完整欣赏的简短入口                                       |
| `featuredWorkIds`   | 本条目中 1–2 件可展示作品或明确命名的原创研究示意        |
| `lesson.sections`   | 2–4 节，每节 `title`、1–4 个 `paragraphs`，可选 `detail` |
| `lesson.reflection` | 一个开放的感受表达引导                                   |
| `activity`          | 可选；标题、5–10 分钟、常见材料、2–4 步，与艺术表达有关  |
| `takeaway`          | 把艺术感受带到生活，不使用成人 AI 速记代替               |
| `parentNote`        | 陪看方法、媒介或示意的边界；接纳感受，不要求画得像原作   |
| `observations`      | 仅兼容旧问答模板，新讲解版不必写；若有，作品引用仍校验   |

`works[].id` 是本条目内可选且唯一的稳定小写标识，引用不使用数组位置。旧档案可以没有 `children`；没有 `lesson` 的旧亲子模板仍须有 `observations` 与 `activity` 才能正常渲染。新日更必须有 `lesson`，活动不强制。

### 局部图

`detail` 包含 `workId`、`imageWidth`、`imageHeight`、`x`、`y`、`width`、`height`、`alt`、`caption`。栅格图以实际像素为单位；SVG 以原图 viewBox 单位为准。引用必须属于 `featuredWorkIds`，尺寸为正，范围不能超出原图。

前端用 SVG 视窗直接放大同一张原图，不另生成、重绘或替换细节。完整图标出范围，可跳到相应讲解；局部提供回看完整作品与打开原图入口，继续显示原图署名。局部沿用原作许可和来源，仍须符合图片收录原则；低分辨率原图放大不会增加真实细节，选范围时须实际查看图像并验收手机与桌面效果。

建筑、包豪斯与数字绘画当前部分图像是本站原创研究示意，要在介绍、署名及讲解中明确说明，不能冒充历史作品、真实建筑照片或艺术家作品。没有合适原作图像仍可收录题材，原创图只解释可靠的视觉关系，不伪造实例。

## 页面与检索

- 每篇一个路由，顶部切换“成人阅读 / 亲子共读 · 5–7 岁”，两版静态生成。共有主题标题保留，亲子版有独立目录及可折叠来源。
- `?edition=family` / `?edition=adult` 优先于浏览器偏好；按钮选择会记忆，禁用存储也能切换。分享复制当前版本，无重复 canonical。
- 缺少 `children` 时不出现空切换或模块，亲子链接回退成人版并提示。无 JavaScript 可通过亲子锚点阅读静态内容。
- 亲子探索可组合版本、分类、标签和关键词，结果显示儿童标题与摘要，链接对应版本。
- 搜索及公开目录只投影儿童标题、摘要与可用状态，不重复图片和讲解正文；sample/draft 继续隔离。
- 使用现有字体、留白和矢量图标，不使用 emoji 图标。

## 每日发布

本机已有每日 Codex 任务在固定专用聊天运行，不增加任务或聊天，不接付费 API。一次研究同一主题及来源，写两版，共同校验、一次提交和部署。读取本文、编辑流程与图片收录原则。

全站 schema 兼容历史数据，新日更另有门禁：

```bash
npm run validate:daily -- src/data/entries/YYYY-MM-DD-slug.json
```

命令校验实际仓库文件、全站内容、上海当天日期、published 状态、当天唯一档案、亲子讲解 `lesson` 和带主题的风格速记。还需运行 `npm run check`、`npm test`、`npm run build`、`npm run test:e2e` 与 `git diff --check`。

关键事实、图片身份与许可须实际核验；程序只能检查结构，不能替代事实判断。必须实际看过原图再选择局部，并确认尺寸、坐标及图文对应。失败时修复或停止发布，不能退回问答模板绕过门禁。

生成任务不改应用代码、密钥、`.env`、CI 或部署配置。依赖本机在线与可用登录状态；自动化配置只留在本机，不入 GitHub。
