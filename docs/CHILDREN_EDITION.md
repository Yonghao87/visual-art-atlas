# 成人阅读与亲子共读

实施日期：2026-10-10。一个主题、一份档案、一套事实来源，两种阅读表达。亲子版面向 5–7 岁，由家长陪读；两版共享 ID、日期、分类、作品、图片许可和来源，不增加档案计数。

## 内容模板

成人版保留现有根层字段、视觉分析、应用与带主题的风格速记。亲子版新增可选 `children`，主阅读文本建议 200–350 字（不计标题和图像署名），用短句介绍具体可见的颜色、形状、线条、空间和材料。

| 字段                | 约定                                                           |
| ------------------- | -------------------------------------------------------------- |
| `ageRange`          | 固定 `5-7`                                                     |
| `title` / `summary` | 儿童标题与两三句介绍；不添加未经来源核实的故事、对白或作者动机 |
| `looking`           | 一句具体观看引导                                               |
| `featuredWorkIds`   | 引用本条目中 1–2 件有展示图像的作品或原创研究实例              |
| `observations`      | 2–3 个开放式问题；每个 `workId` 必须属于已展示作品             |
| `activity`          | 标题、5–10 分钟、常见材料、2–4 个可执行步骤                    |
| `takeaway`          | 一句今天的发现，不使用成人 AI 创作速记代替                     |
| `parentNote`        | 陪看方法；涉及工具时说明成人协助，不要求标准答案或画得像原作   |

`works[].id` 是本档案内可选且唯一的稳定小写标识，儿童引用不使用数组位置。已有档案无需全部迁移；引用的作品必须有 `id` 以及可展示图片。图片沿用根层作品记录，不复制图像或权限数据；许可不明的真实作品保留原站链接。可补充明确命名的原创研究示意，但不能冒充真实作品。

首批样稿为塞尚与浮世绘，其亲子文字从既有核验事实及本地作品图像改写。其他历史条目暂时保持成人阅读，可按同一模板逐步补齐。

## 页面与检索

- 每个档案仅有一个路由。详情顶部切换“成人阅读 / 亲子共读 · 5–7 岁”，两版均静态生成；共有主题标题保留，亲子版有独立目录及可折叠来源。
- `?edition=family` 或 `?edition=adult` 指定阅读方式，URL 优先于浏览器偏好。按钮选择会记忆；禁用本地存储也能切换。分享按钮复制当前阅读版本，无重复 canonical。
- 缺少 `children` 时不显示空切换或模块；亲子链接回退成人内容并提示。没有 JavaScript 时可通过亲子入口锚点阅读静态内容。
- 主导航“亲子共读”进入 `/explore/?edition=family`。版本筛选可与分类、标签及关键词组合，亲子结果显示儿童标题和摘要，并链接对应版本。
- 搜索与公开目录只投影亲子标题、摘要及可用状态，不复制活动正文；sample/draft 继续隔离。

## 每日发布

本机现有 Codex 定时任务在专用聊天中运行，不新增第二个任务，也不接付费 API。每日研究一次主题及来源，然后生成成人与亲子两版，共同校验、一次提交与部署。每日任务必须读本文及图片收录原则。

全站 schema 允许历史条目没有亲子版；新日更另有强制门禁：

```bash
npm run validate:daily -- src/data/entries/YYYY-MM-DD-slug.json
```

此命令检查实际仓库文件、全站内容、上海当天日期、published 状态、当天唯一档案、完整亲子版与风格速记。随后仍须运行 `npm run check`、`npm test`、`npm run build`、`npm run test:e2e` 和 `git diff --check`。关键事实、图片身份与许可必须实际核验，填写字段不是核验本身。失败时修复或停止发布，不让缺版、缺图或未核验数据绕过门禁。

生成内容不得改动密钥、`.env`、CI、部署配置或应用代码。任务依赖本机在线及可用的 Codex/GitHub 登录环境，自动化配置留在本机，不入 GitHub。
