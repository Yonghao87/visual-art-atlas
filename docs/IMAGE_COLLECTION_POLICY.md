# Visual Art Atlas 图片收录原则

制定日期：2026-10-09；修订日期：2026-10-10。用途：选题、内容收录、编辑补图及后续内容入库的图片标准。

**以主题和学习价值决定收录对象，再为内容寻找和补充图片。图片可用性不决定题材范围，也不要求为了补图更换重要作品。作品图片必须与作品记录对应。**

本规范沿用 `PROJECT_SPEC.md` 中允许缺图数据的 MVP 规则。内容事实与来源核验、图片展示许可分别处理：一件作品可以有完整文字记录和来源链接，同时暂未收录图片。当前代码允许 `cover` 和 `work.image` 为 `null`；详情页会以紧凑文字行呈现缺图作品并保留其来源入口。

## 1. 收录目标

- 七大领域按研究兴趣、代表性和学习价值选题，覆盖古典与现代、知名与小众、不同媒介和地区。
- 重要艺术家、作品和设计方法即使暂时缺图，也保留档案与作品记录，继续补充来源和图片。
- 首页、探索卡片、档案封面提供完整的主题视觉，可采用明确标注的本站原创排版或主题图。
- 有图片的实例展示图像；暂时缺图的实例采用紧凑的文字参考和原站链接，避免大面积空图框。
- 已展示图片符合对应使用条件，图像身份、署名与来源可追溯。

图片完整度作为持续改进目标，不作为选题或内容发布的数量门槛。不能承诺任意指定作品一定能取得可转载原图；找到可用图片后逐步补齐。

## 2. 先确定主题，再补充图片

1. 根据七大领域、研究兴趣和知识关联确定主题。
2. 选择能说明主题的代表作品或研究实例，核验作者、年代、版本和可靠来源。
3. 编写视觉分析与学习内容；在写作过程中或完成后寻找对应图片。
4. 对取得的图片核验身份、具体许可和画质，保存可用文件、署名与证据。
5. 暂未取得图片的对象保留文字记录和来源链接，登记待补事项；完成现有内容校验和展示检查后发布。

代表作品通常选择 2–4 件，数量取决于主题需要。选题、主要研究对象和重要参考作品不因缺图被自动删除、更换或缩小范围；只有内容判断需要调整时才修改作品清单。人物或单件作品专题也允许暂未收录图片，保留真实作品信息和观看入口。来源或事实无法核验时仍保留草稿。

未来内容入库流程应支持补图队列。网络查询、下载或图像授权暂未解决时，记录原因并继续处理已有可靠来源的内容；不能生成假图源，也不能把未知许可标为已授权。本规范不启用每日自动发布。

## 3. 图源优先级

| 顺序 | 图源                                 | 收录条件                                                               |
| ---- | ------------------------------------ | ---------------------------------------------------------------------- |
| 1    | 博物馆、档案馆等机构的开放访问图像   | 具体对象或图像明确标为 Public Domain、CC0 或其他允许本站使用的开放许可 |
| 2    | 创作者、摄影师或权利人发布的开放图像 | 确认具体文件及许可版本，满足署名、修改说明等条件                       |
| 3    | Wikimedia Commons 等开放素材平台     | 回到文件详情页核对作者、来源和许可；搜索结果的“可用”标签不能替代核验   |
| 4    | 已取得明确许可的图像                 | 保存授权范围，确认允许公开网站展示及本地托管；裁切等修改另按授权执行   |
| 5    | 本站原创主题视觉或技法示意图         | 标明用途和创作者，不临摹受保护作品后宣称完全原创，不冒充作品原图       |

常规素材库优先采用 Public Domain、CC0、CC BY 和 CC BY-SA。带 NC、ND 或其他限制的素材按具体用途单独评估，不自动进入常规素材库。这是本站的维护选择，不表示这些许可一律不能使用。

不能将“在官网展示”“搜索得到”“图片可下载”“注明出处”或“用于学习”自动认定为可转载。也不根据创作者仍在世或作品较新就一律拒绝：有明确许可且符合用途的图片仍可收录。照片中涉及第三方作品时，对已有证据具体判断，避免把摄影许可自动扩大为所有权利的许可。

### 常见来源与非商业学习用途

- **创作者个人网站**：若能确认发布者是该作品的权利人，并且站点/作品页给出允许本站展示的许可，可按其条件收录；没有许可说明时，可以向创作者申请展示授权。保留授权回复、图片范围、公开网站展示用途、署名方式及允许的裁切范围。
- **ArtStation**：作品公开可见不代表访客获得站外转载授权。ArtStation 条款保留创作者对原创内容的所有权，并将平台取得的许可描述为提供、改进和推广 ArtStation 服务所需；逐件检查作品说明或向作者申请许可。
- **Pinterest**：Pin 可能是转存作品，先追溯到原作者/原始页面。Pinterest 条款不能当作每个 Pin 的独立开放许可，也不应只凭 Pin 下载并上传到本站。
- **Google 图片**：用于发现候选图片。即使使用“使用权限”筛选，也要回到图片托管网站和许可页面确认，因为 Google 说明筛选信息来自托管站点或图片提供者。
- **非商业、学习用途**：这是判断特定许可条件（如 NC）或法定例外时的重要事实，但不自动让所有网络图片都可转载。中国《著作权法》第二十四条列有个人学习、研究或欣赏等例外，并要求署名、不得影响作品正常使用或不合理损害权利人合法权益；对作品进行介绍、评论或说明问题时，也规定了适当引用的情形。公开网站面向不特定访问者，是否满足例外取决于实际页面、引用必要性、数量和传播方式，不能只凭“本站非商业”一项下结论。
- **下载与嵌入**：将文件下载到仓库并由本站提供，属于本地再发布；远程热链/嵌入也不自动获得授权，还要看权利人许可、平台功能和使用条款。优先使用权利人明确允许的官方嵌入；否则取得展示授权后再保存本地副本。

对于符合许可的学习型素材，本站可以采用 NC 授权或经创作者直接给出的非商业展示授权，并记录“非商业”的适用范围。ND 素材按许可原样展示，避免裁切或其他可能构成改编的处理；卡片裁切时使用另一张允许裁切的图。仍无法判断法定例外或权利范围时，保留作品链接并采用有授权的替代图/原创示意图。

## 4. 封面与作品图分别处理

| 位置                           | 首选                         | 补足方式                                                            | 展示要求                                                                            |
| ------------------------------ | ---------------------------- | ------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| 首页、探索卡片、详情封面       | 本篇的真实作品图或相关纪实图 | 在许可允许时使用作品局部；或制作本站原创主题视觉                    | 分别标注“作品图”“纪实图”“作品局部”“主题插画”或“本站排版封面”；详情展示署名与来源    |
| 代表作品画廊                   | 对应作品的真实图像           | 同作品的另一授权版本/视角；暂未取得图片时保留紧凑文字参考与原站链接 | 图片和标题、作者、年代、媒介/版本一致；更换版本时同步修订分析，不为补图自动更换作品 |
| 技法、材料、设计方法的研究实例 | 授权教程图或实作示例         | 本站原创步骤图、色块练习、构图或空间示意图                          | 标注“技法示意”或“本站研究实例”，写明真实制作者；不能挂在具体作品名下冒充其原图      |

封面可以复用本篇作品图；不要求为了数量寻找无关图片。一张图片不应在同一画廊重复计为多个独立作品。原创封面也不计入真实作品图数量。

AI 生成图如将来使用，仅作为明确标注的主题插画或创作实验，并记录生成来源；不能替代艺术家真迹、建筑照片或产品实拍，也不能自动标为 `public_domain` 或 `own_work`。当前阶段使用已有合法素材和自行绘制的 SVG/图解即可，无需付费 AI API。

## 5. 遇到缺图时的处理顺序

1. 查找同作品的开放图像、其他馆藏版本或权利人的许可；核对图像实际版本。
2. 在权利人或平台明确允许的情况下使用官方嵌入；需要申请许可时登记事项，联系作者须有用户授权。
3. 对技法主题，可增加原创且准确的示意图，将其另行命名为研究或技法示意；保留原有重要参考对象。
4. 无法直接展示的作品继续保留在 `works` 中，以紧凑文字参考、作者、年代和原站链接呈现，不保留大面积空图框。
5. 在来源记录中登记缺图原因，例如未找到图源、许可待确认、下载失败或画质不足，后续逐步补齐；不以缺图数量阻止有可靠内容的档案发布。

例如，“现代建筑”仍可研究萨伏伊别墅，暂时缺图时保留该作品记录、分析和原始来源，封面采用原创空间构成视觉。取得可用建筑图后再补入。原创的架空柱结构示意另命名为研究实例，不能使用“萨伏伊别墅”的作品身份。拉姆斯 620 与 606 的图片同样不能互换名称。

## 6. 记录与视觉质量

沿用现有 JSON 的 `src`、`alt`、`credit`、`rights`、`sourceUrl`、`licenseUrl` 和 `permissionNote`，保持图片事实与正文来源分开核对。原图身份、版本差异、原创示意用途以及裁切/其他修改，目前写入 `credit` 和核验记录，不新增未经实现的必填字段。

第三方图像在 `docs/evidence/` 保存核验日期、对象/文件标识、来源页、图像下载地址、许可及适用范围、原始署名和本地文件校验值。本站原创图像保留源文件及制作说明。授权往来如含私人信息，应存于非公开位置，公开记录仅保留必要的授权范围。

- 优先保存到 `public/images/`，站点运行不依赖外站热链。
- 目标长边至少 1200px；以细节为主的作品优先更高分辨率。字体样本、历史小图等例外需有可读的实际预览。
- 默认保留原始构图和色彩；详情使用完整图，卡片裁切不能遮掉本篇分析重点。许可要求的修改说明和适用的相同方式共享条件随图保留。
- `alt` 客观描述图像，避免只重复标题；署名、作品来源和图像许可在读者可见的位置展示。

## 7. 发布验收与展示优化

发布检查以内容可靠、图片使用条件和展示可用性为准：

- 封面图片如存在，应可解码且路径正确；缺图时使用本站主题视觉或排版封面。
- 作品/研究实例有可靠来源；缺少 `image` 允许通过内容校验，不新增“所有作品必须有图”的阻断条件。
- 所有填写了 `src` 的图片文件存在且可解码，权利状态支持展示，署名和许可/授权记录完整。
- 编辑已核对图片与作品/实例身份、主题、版本和分析对应；程序不能仅凭许可字段证明授权成立。
- 1440px 和 390px 下缺图条目采用紧凑文字参考，没有大面积空框、图片 404 或失真拉伸，署名与来源链接可用。
- 图片加载失败后仍有清晰的回退和原始来源入口。

后续实施重点是记录补图进度，以及检查实际展示的图片文件。现有数据模型保留可空图片字段；不因图片未齐全阻断题材收录或引入备用选题替换规则。

## 8. 依据

以下为具体许可与开放访问的核对入口，不代表其中每一张图片自动满足本站用途：

- [The Met Open Access](https://www.metmuseum.org/hubs/open-access)：其开放访问公版作品图像按 CC0 提供。
- [Creative Commons 许可类型](https://creativecommons.org/cc-licenses/)：各许可的使用、修改与商业用途条件。
- [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/deed.en)：署名、许可链接和修改说明。
- [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/deed.en)：改编的相同或兼容许可要求。
- [Creative Commons FAQ](https://creativecommons.org/faq/#does-a-creative-commons-license-give-me-all-the-rights-i-need-to-use-the-work)：第三方内容及许可范围的核对。
- [中华人民共和国著作权法](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html)：第二十四条的合理使用情形与条件。
- [Google 图片使用权限说明](https://support.google.com/websearch/answer/29508)：筛选后仍需回到托管方核对具体许可。
- [Pinterest 服务条款](https://policy.pinterest.com/zh-hans/terms-of-service)：平台内容、用户责任与使用边界。
- [ArtStation 服务条款](https://www.artstation.com/tos)：创作者内容权属及平台许可范围。
